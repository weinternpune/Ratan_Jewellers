PROBLEM:
--------
❌ Dashboard showing ₹0.0L revenue
❌ Invoice status showing "Pending" when should be "Paid"
❌ Error: src\lib\billingApi.ts (109:9) @ handleApiError

ROOT CAUSE:
-----------
⚠️  BACKEND SERVER IS NOT RUNNING!

The frontend cannot fetch invoice data because the backend API is not started.
This is why you see the error and no data in dashboard.


================================================================================
                            ⚡ QUICK FIX
================================================================================

STEP 1: Start MongoDB
---------------------
Open Command Prompt as Administrator:

    net start MongoDB


STEP 2: Start Backend & Frontend
---------------------------------
Double-click this file:

    START_SERVERS.bat

OR manually run these commands:

Terminal 1 (Backend):
    cd backend
    npm run dev

Terminal 2 (Frontend):
    cd frontend
    npm run dev

⚠️  KEEP BOTH TERMINALS OPEN!


STEP 3: Verify It's Working
----------------------------
Open browser:

1. Check backend: http://localhost:5000
   Should show: "Ratan Jewellers Backend API is running successfully"

2. Check frontend: http://localhost:3000/admin/billing
   Should show invoices loading correctly

3. Check dashboard: http://localhost:3000/admin/dashboard
   Should show correct revenue (not ₹0.0L)

================================================================================
                            ❓ TROUBLESHOOTING
================================================================================

MongoDB not running:
  → net start MongoDB

Port 5000 already in use:
  → netstat -ano | findstr :5000
  → taskkill /PID <PID> /F

Backend won't start:
  → cd backend
  → npm install
  → npm run dev

Frontend won't start:
  → cd frontend
  → npm install
  → npm run dev

Dashboard still shows ₹0:
  → Make sure backend is running (check localhost:5000)
  → Clear browser cache (Ctrl+Shift+Del)
  → Reload page (F5)

Invoice status not updating:
  → Ensure backend is running
  → Check browser console for errors
  → Refresh invoices page
