================================================================================
                    🔧 QUICK FIX: Error 429 (Too Many Requests)
================================================================================

ERROR:
------
Console AxiosError
Request failed with status code 429


WHAT THIS MEANS:
----------------
You hit the API rate limit (too many requests in short time).
The backend was set to allow only 100 requests per 15 minutes.


================================================================================
                            ✅ SOLUTION (2 STEPS)
================================================================================

STEP 1: Restart Backend Server
-------------------------------
The rate limit has been increased from 100 to 1000 requests.
You MUST restart the backend for this to take effect.

Method A: Using START_SERVERS.bat
  1. Close the "Ratan Jewellers Backend" terminal window
  2. Double-click START_SERVERS.bat again

Method B: Manual Restart
  1. Go to backend terminal
  2. Press Ctrl + C
  3. Run: npm run dev


STEP 2: Clear Browser Cache & Reload
-------------------------------------
  1. Press Ctrl + Shift + R (hard reload)
  2. Or F12 → Network tab → Check "Disable cache" → Reload


================================================================================
                         WHAT WAS CHANGED
================================================================================

File: backend/src/server.ts

Before (Too Low):
  Rate Limit: 100 requests per 15 minutes

After (Fixed):
  Development:  1000 requests per 15 minutes ✅
  Production:   100 requests per 15 minutes


================================================================================
                         WHY THIS HAPPENED
================================================================================

Common causes of hitting rate limit:

1. ✅ Dashboard auto-refreshes every 30 seconds
2. ✅ Multiple browser tabs open (each makes API calls)
3. ✅ Real-time calculation on every keystroke
4. ✅ Multiple form fields updating simultaneously
5. ✅ Previous limit (100) was too low for development


================================================================================
                         AFTER RESTART
================================================================================

You will be able to make:
  • 1000 API requests per 15 minutes (instead of 100)
  • That's 10x more requests!
  • Should be more than enough for development

Rate limit resets every 15 minutes automatically.
